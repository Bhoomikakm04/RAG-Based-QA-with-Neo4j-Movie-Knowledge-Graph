# Project Plan

## Phase 1 — Database

- Connect Python to Neo4j Aura.
- Verify the Movies graph.
- Inspect labels and relationship types.
- Validate read-only Cypher queries.

## Phase 2 — LLM

- Verify Ollama.
- Verify the Mistral model.
- Test a simple local generation request.

## Phase 3 — GraphRAG

- Classify user question.
- Select/generate a safe Cypher query.
- Retrieve graph evidence.
- Build a context.
- Generate a grounded response.

## Phase 4 — UI

- Dashboard.
- Ask Question.
- Graph Explorer.
- Evaluation.

## Phase 5 — Evaluation

Evaluate:
- retrieval success,
- query intent classification,
- answer groundedness,
- latency,
- failure cases.

## Phase 6 — Documentation

Prepare:
- architecture,
- database schema,
- methodology,
- screenshots,
- test cases,
- evaluation,
- limitations,
- future enhancements.
